# LifeSync 🌟

LifeSync is a beautifully designed, all-in-one Life Operating System built with React Native and Expo. It seamlessly integrates your tasks, habits, finances, health, and meals into a single, cohesive dashboard to help you organize your life and build better routines.

## ✨ Features

- **✅ Task Management**: Organize your daily to-dos with an intuitive interface.
- **🌱 Habit Tracking**: Build consistency with daily habit streaks and progress tracking.
- **💰 Finance Tracker**: Monitor your daily expenses, visualize spending across categories, and stay within your budget.
- **🎯 Goals Planner**: Set long-term milestones and track your journey to achieving them.
- **🍳 Meal Planning & Recipes**: Save your favorite recipes, complete with prep times, calories, and ingredients.
- **🛒 Smart Groceries**: Manage your shopping lists seamlessly.
- **🧘‍♂️ Journal & Mood Tracker**: Log your daily thoughts and track your emotional well-being using emoji moods.
- **🍅 Focus Mode**: A distraction-free Pomodoro timer featuring a stunning, animated progress ring to help you get deep work done.
- **🏃‍♂️ Fitness & Activity**: Close your daily rings (Move, Exercise, Hydration) inspired by Apple Fitness.
- **🎉 Life Wrapped**: At the end of the year, view a beautiful full-screen presentation celebrating your consistency, completed tasks, saved money, and top moods!

## 🛠️ Tech Stack

- **Framework**: [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
- **Navigation**: [Expo Router](https://docs.expo.dev/router/introduction/) (File-based routing)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Animations**: [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/) & React Native SVG
- **Storage**: AsyncStorage for persistent, on-device local storage.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed, and either the [Expo Go](https://expo.dev/client) app on your mobile device or an iOS/Android emulator setup.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/lifesync.git
   cd lifesync
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the Expo server**
   ```bash
   npx expo start
   ```

4. **Run the App**
   - Press `a` to open on an Android emulator.
   - Press `i` to open on an iOS simulator.
   - Or, scan the QR code with your phone's camera (iOS) or the Expo Go app (Android).

## 🎨 Design Philosophy
LifeSync is designed with a massive emphasis on beautiful UI/UX. It features smooth spring animations, unified frosted-glass components, deep dark-mode support, and a minimalist navigation system to keep incredible power from feeling cluttered.
